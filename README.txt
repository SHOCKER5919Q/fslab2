FSWD LAB SET 1-15 — ORIGINAL PROGRAMS

Each set has separate folders for its two programs.
The original experiment code is stored in its own file.
React projects include Vite support files; the original React code is App.jsx.
Only directory organization and run/setup notes have been added.

React:
  cd setXX/program
  npm install
  npm run dev

Node:
  node filename.js
For Express programs: npm init -y && npm install express
For Mongoose program: npm init -y && npm install mongoose

Mongo shell:
  start mongod, then run mongosh filename.mongosh.js

HTML:
  open the .html file in a browser.

Set-5:
  echo Hello Saket > input.txt
  node blocking.js
  node nonblocking.js

Port 3000 is used by server programs. Stop an existing server before starting another.
